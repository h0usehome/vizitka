# Заявки с сайта в Telegram

Форма «Оставить заявку» отправляет имя и телефон на Cloudflare Worker, а он пересылает их боту в Telegram.
Токен бота хранится в Cloudflare, на сайте его не видно. Бесплатного тарифа Cloudflare хватает с запасом.

## 1. Создать бота
1. В Telegram напишите [@BotFather](https://t.me/BotFather), команда `/newbot`. Сохраните **токен**.
2. Создайте группу для заявок, добавьте туда бота и обоих участников (или просто напишите боту `/start` в личке).
3. Узнайте **chat_id**: напишите в группе любое сообщение и откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Число в `"chat":{"id": ...}` и есть chat_id
   (у групп оно начинается с минуса).

## 2. Создать Worker
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Create Worker**.
2. Нажмите **Edit code**, замените весь код на содержимое `lead-worker.js`, нажмите **Deploy**.
3. В **Settings → Variables and Secrets** добавьте:
   - `BOT_TOKEN`: тип **Secret**, значение: токен бота;
   - `CHAT_ID`: chat_id (несколько через запятую, если нужно);
   - `ALLOWED_ORIGIN`: `https://h0usehome.github.io` (без слеша в конце; если подключите свой домен, допишите его через запятую).
4. Скопируйте адрес Worker, например `https://lead.ваш-логин.workers.dev`.

## 3. Подключить к сайту
В `main.js` найдите строку `var LEAD_ENDPOINT = '';` и вставьте адрес Worker между кавычками.
Закоммитьте, после публикации отправьте тестовую заявку.

Пока адрес не указан, форма не притворяется, что отправила заявку, а предлагает позвонить.
